# 🤖 AI-Powered Spare Parts Recognition & SAP EWM Integration

## 📌 Project Overview

This project focused on developing and rolling out an AI-powered mobile solution for a large European transportation company to improve spare parts identification and ordering in maintenance operations.

Maintenance employees used tablets and smartphones to take pictures of defective train components. A machine learning model analyzed the images and suggested matching spare parts. After the employee selected the correct material, the application triggered the downstream process in SAP Extended Warehouse Management.

I worked as Technical Solution Consultant and Project Lead across the AI, mobile application and SAP workstreams. My role combined technical project management, solution design, requirements engineering and coordination of the machine learning training process.

---

## 🎯 Business Challenge

Maintenance employees often had to identify and order replacement parts for defective train components, while the correct material number was not always immediately known.

With more than 20,000 material numbers and several warehouse and maintenance locations, manual identification was time-consuming and depended heavily on local experience.

The goal was to simplify the process by combining mobile image recognition with an integrated SAP EWM workflow.

Key topics included:

- AI-based recognition of physical spare parts
- Mobile use on tablets and smartphones
- Machine learning training data and validation
- SAP EWM integration
- Material and inventory information
- End-to-end software delivery
- Rollout across operational locations

## 🧠 Machine Learning & Training Data

One of the core challenges was creating sufficient and consistent training data for the image recognition model.

The spare parts were photographed in a dedicated photo box under controlled conditions. Multiple images were captured for each component from different angles and then mapped to the corresponding SAP material number.

```text
Physical Spare Part
        │
        ▼
Dedicated Photo Box
        │
        ▼
~20 Images per Part
        │
        ▼
Image Classification
& Material Mapping
        │
        ▼
Training Dataset
        │
        ▼
Machine Learning Model
        │
        ▼
Recognition & Validation
```

I coordinated this process across several locations and worked with the AI technology partner on the training and validation of the recognition model.

Key topics included:

- Consistent image capture under controlled conditions
- Correct mapping between images and SAP material numbers
- Coverage of different viewing angles
- Validation of recognition accuracy
- Re-training where model quality was insufficient

The photo box was used specifically to build a standardized training dataset. Smartphones and tablets were not used for the initial model training.

## 📱 Mobile Application & User Flow

Once the model had been trained and the application was ready for operational use, maintenance employees used tablets and smartphones directly in the workshop.

The user flow was intentionally simple:

```text
Defective Component
        │
        ▼
Photo via Tablet / Smartphone
        │
        ▼
AI Recognition
        │
        ▼
Suggested Spare Parts
        │
        ▼
Employee Selects Material
        │
        ▼
Material / Inventory Check
        │
        ▼
SAP EWM Process
```

The objective was to reduce manual searches and make spare parts identification part of the technician's normal maintenance workflow.

The employee did not need to know the exact SAP material number beforehand. The AI model narrowed down the possible components and supported the final selection.

## 🔗 SAP EWM Process

Once the correct spare part was selected, the mobile application triggered the downstream warehouse process in SAP EWM.

The process followed the existing warehouse operating model.

```text
Spare Part Selected
        │
        ▼
Material Request
        │
        ▼
Warehouse Task / Picking
        │
        ▼
Goods Issue
        │
        ▼
Material Movement
        │
        ▼
Delivery to Service Employee
        │
        ▼
Part Used / Installed
        │
        ▼
Consumption Registered in SAP
```

I worked with the SAP project team on the functional design and integration requirements across:

- Material master data
- Inventory availability
- Warehouse tasks and picking
- Goods issue
- Material movement
- Consumption and installation recording

The goal was to keep the user experience simple while using the established SAP EWM processes in the backend.
